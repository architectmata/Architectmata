# Short process videos

Place approved, web-ready process clips in this directory.

Recommended files:

- `summer-hangout-making.mp4` — H.264 MP4, muted source, 6–12 seconds, ideally under 2 MB
- `summer-hangout-making.webm` — optional WebM alternative
- `summer-hangout-making-poster.webp` — still poster matching the video crop

Use the `LoopingVideo` component from `src/components/looping-video.tsx`. Keep clips short,
avoid showing children’s faces, and use no more than one moving element per section.
